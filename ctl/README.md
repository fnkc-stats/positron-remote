# FNKC Projects

Открывает проект в отдельном контейнере, на сервере или на этом компьютере, и подключает к нему Positron. Репозиторий клонируется внутри контейнера; проект в списке называется как репозиторий в Gitea. Нужен Positron той версии, для которой собран образ проекта (сервер Positron входит в образ).

Команды (Cmd/Ctrl+Shift+P):

- **FNKC Projects: Open Project…** (если данные проекта зашифрованы, спросит, расшифровать ли их)
- **FNKC Projects: Stop Project…** (тома сохраняются; зависимости фиксируются отдельно командой `fnkc-projects snapshot`)
- **Delete Project…** (кнопка с корзиной у остановленного проекта на панели FNKC; удаляет контейнер, все тома проекта и его сеть; сначала проверяет, что не потеряется: если вся работа уже в Gitea, так и говорит; если нет — открывает отчёт со всеми файлами, папками и коммитами, которых нет в Gitea, и предлагает открыть проект, чтобы закоммитить и запушить; в обоих случаях перечисляет удаляемые тома; то же в командной строке: `fnkc-ctl remove <проект> --host <хост>`)
- **FNKC Projects: Remove SSH Configuration** (убирает строку `Include fnkc/*.conf` из `~/.ssh/config` и папку `~/.ssh/fnkc`; первое открытие проекта спрашивает, прежде чем добавить эту строку; записи удалённых проектов исчезают из `~/.ssh/fnkc` сами)
- **FNKC Projects: Build Environment…** (новый образ в GitHub CI для серии R и версии Positron, по умолчанию — этой; затем предлагает закрепить его в `container.json` открытого проекта; нужен `gh auth login`)
- **FNKC Projects: Show Log**

Панель **Environment Images** (под списком проектов, значок FNKC) — для администраторов: R-окружения `r-env` в реестре по сериям R (дата сборки, коммит, версия R, где используется), под каждым — слои с сервером Positron, которые для него собраны; отметка, закрепляет ли шаблон Gitea каждой серии самое новое окружение (число на значке панели — шаблоны, которые отстали), и образы на каждом хосте с размером и числом контейнеров всех пользователей. Кнопки в строке: скопировать закрепление, открыть `renv.lock` сборки; в контекстном меню — закрепить в `container.json` открытой папки, открыть запуск CI и коммит, сравнить с самой новой сборкой, удалить неиспользуемый образ с этого компьютера или скопировать команду удаления для сервера. Панель только читает и обновляется кнопкой Refresh; то же в командной строке: `fnkc-ctl images`; что можно удалить из реестра — `fnkc-ctl images --cleanup` ([руководство оператора](https://github.com/fnkc-stats/positron-remote/blob/main/docs/operations.md#образы-окружения)).

Настройки: *FNKC Projects* в настройках Positron или `~/.config/fnkc-ctl/config.json`.
Тот же код доступен как командная строка `fnkc-ctl` (см. README репозитория).
