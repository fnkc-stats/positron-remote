# Дополнительно

Всё, что не нужно для обычной работы. Основная инструкция: [manual.md](manual.md).

## Добавить R-пакет в проект

```r
install.packages("pkg")
renv::snapshot()
```

Закоммитьте изменённый `renv.lock`: у коллег пакет установится сам при следующем запуске консоли. Пакет хранится в проекте и переживает остановку. Нужен доступ сервера к интернету; если его нет, попросите администратора добавить пакет в окружение.

Не выполняйте `renv::init()` и не меняйте `.libPaths()`.

## Сменить версию R в существующем проекте

1. Возьмите `container.json` и `renv.lock` из шаблона нужной версии (`template-r-<версия>`) и замените ими свои. Пакеты, которые вы добавляли сами, добавьте заново (см. выше).
2. Закоммитьте и запушьте.
3. Остановите проект (кнопка **■**) и откройте снова.

После любого изменения `container.json` проект нужно остановить и открыть заново, иначе продолжит работать старое окружение.

## Запустить проект на своём компьютере

Если в `config.json` есть хост `local`, на панели FNKC он виден как «this computer». Нажмите **+** рядом с ним (Open Project Here…). Нужен Docker: на macOS — `brew install colima docker`, на Windows — то, что предложит **Check Setup**. Перед переходом между сервером и компьютером запушьте работу: это разные копии проекта.

## Долгие расчёты

Запускайте их из терминала проекта:

```bash
fnkc-projects run Rscript analysis.R
fnkc-projects run quarto render report.qmd
```

Не останавливайте проект, пока идёт расчёт. Сохраняйте промежуточные результаты: при нехватке памяти R завершится (консоль скажет об этом при следующем запуске).

## Не хватает памяти

Загружайте данные частями (arrow, duckdb, data.table), удаляйте большие промежуточные объекты (`rm()`, `gc()`). Если не помогает, напишите администратору. Сколько памяти занято, видно на панели FNKC рядом с работающим проектом.

## Зашифрованные данные (git-crypt)

Только с согласия администратора: он скажет, на каком сервере можно. Укажите путь к ключу в **Settings → FNKC Projects → Git Crypt Key**, имя сервера — в `decryptionHosts` в `config.json`. Кнопки для этого нет: Cmd/Ctrl+Shift+P → **FNKC Projects: Open Project with Decrypted Data…**. Закончив, выполните в терминале проекта `fnkc-projects lock`.

## Если что-то не работает

- Нажмите **Check Setup** на панели FNKC.
- Обновите панель кнопкой ⟳.
- Лог: **View → Output**, в списке справа выберите **FNKC Projects**. Пришлите его администратору.
