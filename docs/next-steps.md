# Дальнейшие шаги

Состояние на 16.11.2026: `positron-ctl` и расширение *Positron Projects* работают на Mac (Colima);
серверная часть проверена на «сервере-дублёре» (контейнер с sshd на этом же компьютере). Ниже — что нужно
сделать людям, по порядку приоритетов: сервер, Windows, остальное. Подробности по каждой команде — в
[README](../README.md).

## 1. Пилот на настоящем сервере

**Кто:** администратор сервера (нужен `sudo`). **Нужно:** Linux с Docker Engine и Node.js 20+; подойдёт
и небольшая временная виртуальная машина.

1. На своём компьютере собрать пакет для сервера:
   ```bash
   cd ctl && npm ci && npm run server-bundle
   scp dist/positron-ctl-server.tar.gz <админ>@<сервер>:
   ```
2. На сервере установить:
   ```bash
   tar -xzf positron-ctl-server.tar.gz && sudo ./positron-ctl-server/install.sh
   ```
   Скрипт сам проверит Docker, Node.js и настройки sshd и скажет, если чего-то не хватает.
3. При необходимости поправить `/etc/positron-ctl/agent.json`: лимиты памяти и CPU на контейнер,
   `idleMinutes` (через сколько минут без подключений контейнер останавливается сам; по умолчанию 120).
4. Добавить себя (ключ — тот же, что в Gitea):
   ```bash
   sudo positron-ctl admin add-user <имя> <имя>.pub
   ```
   Имя — латинские строчные буквы и цифры.
5. В Positron: настройки → *Positron Projects → Hosts*:
   `[{ "name": "server", "ssh": "positron@<сервер>" }, { "name": "local" }]`.
6. **Positron Projects: Open Project…** → проект → *server*. Проверить:
   - открывается окно, R-консоль запускается и отвечает (`1 + 1`);
   - внизу слева кнопка **■ <проект> (server)** останавливает проект и закрывает окно;
   - закрыть окно без остановки — через `idleMinutes` контейнер останавливается сам
     (`sudo positron-ctl agent list --user <имя>` на сервере).
7. Если что-то не так — **Positron Projects: Show Log** и вывод `install.sh` прислать тому, кто ведёт проект.

На что обратить внимание: доступ сервера к `ghcr.io` и `cdn.posit.co` (прокси, файрвол), свободное место
под образ `r-env` (около 3,5 ГБ) и тома проектов.

## 2. Пилот на Windows

**Кто:** один коллега с Windows. **Нужно:** Windows 10/11, права администратора один раз (включение WSL),
включённая виртуализация (обычно включена).

1. Установить Positron, Git for Windows, SSH-ключ добавить в Gitea.
2. Установить расширение: *Extensions → … → Install from VSIX* → `positron-projects.vsix`.
3. **Positron Projects: Set Up Docker on This Computer** — откроется окно PowerShell; если попросит,
   перезагрузить Windows и запустить команду ещё раз.
4. Открыть проект на этом компьютере и на сервере, как в п. 1.6.
5. Прислать результат и лог (**Show Log**), особенно если не открылось окно проекта или не запустилась консоль R.

## 3. Проекты

- Добавить `container.json` в существующие проекты (сейчас они берут образ из `defaultImage`) и в шаблон
  проекта в Gitea — образец: [project-template/container.json](../project-template/container.json).
- Решить, когда отправлять изменения этого репозитория на GitHub (пока всё только локально).

## 4. Что делается в коде параллельно

- Боковая панель расширения: список проектов по хостам, кнопки «Открыть» и «Остановить».
- Проверки при первом запуске с понятными подсказками: Docker, SSH-ключ, ssh-agent, доступ к Gitea и серверу.
- После пилотов — простая инструкция для коллег ([workflow.md](workflow.md) будет переписана).
